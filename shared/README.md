# shared

Shared TypeScript types used by both `server` and `client` packages.

## Types

- **board.ts** — `Cell`, `BoardGrid`, `CellCoord`, `BoardMetadata`
- **room.ts** — `RoomPhase`, `PlayerInfo`, `GameStats`, `RoomState`
- **ruleset.ts** — `Ruleset` plugin interface
- **events.ts** — `ClientToServerEvents`, `ServerToClientEvents` Socket.IO event maps
